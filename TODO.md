
# Forest Quest — Production Board

## Current playable foundation

- [x] Five authored level archetypes: balanced trail, vertical parkour, combat arena, hazard gauntlet, and mixed trial.
- [x] Ten-level campaign rotation with later-cycle enemy-speed escalation.
- [x] Double jump, fireball combat, checkpoints, patrol enemies, boss encounters, coins, score, and restart flow.
- [x] Trader menu that pauses gameplay and exposes mobility, survival, and fire progression.
- [x] Fullscreen control and larger responsive playfield.

## Next build — challenge and fairness

- [ ] Play every archetype from spawn to checkpoint; tune jump distances and spike placement from actual failures.
- [x] Replace the repeated five-stage route with ten authored layouts and a fifteen-level campaign, including pure vertical ascent/descent stages.
- [x] Turn out-of-bounds falls into a short visible void fall, then a loss/respawn instead of leaving the player stranded.
- [x] Add kill-callout particles, stage-specific atmospheric tints, fog, and storm lightning.
- [x] Add a boss finisher sequence with impact freeze, soul absorption, reward reveal, and a longer readable void-death sequence.
- [x] Add a second enemy behavior using the existing Owlet assets: aerial patrol / dive attack.
- [x] Make combat arenas lock until their enemy wave is cleared, with a clear visual gate.
- [ ] Add a safe practice room for movement and fireball upgrades.

## Next build — expression and polish

- [ ] Use unused forest and monster sprite sheets for hit, death, run, and attack feedback.
- [ ] Add impact particles, enemy hit flashes, coin pickup sound, and boss attack tells.
- [ ] Add a proper campaign map / level-select screen with stage tags and completion medals.
- [ ] Add saved local progress only after replayability and restart behavior are stable.
